# MundoVino 🍷

Este é um aplicativo em React Native (Expo) voltado para a assinatura de vinhos para iniciantes. Desenvolvido como atividade prática, o aplicativo possui 6 telas compondo um fluxo completo desde o login até a confirmação da compra do pacote de assinatura.

## 🎯 Objetivo
Facilitar a assinatura de pacotes mensais com seleções variadas de vinhos, permitindo que iniciantes explorem novos sabores de forma intuitiva.

## 📱 Telas do Aplicativo
1. **Login:** Acesso com e-mail e senha.
2. **Cadastro:** Criação de conta para novos usuários.
3. **Catálogo:** Lista de pacotes de assinatura disponíveis utilizando `FlatList`.
4. **Detalhes/Carrinho:** Resumo das características do pacote selecionado.
5. **Pagamento:** Preenchimento de endereço e dados do cartão.
6. **Confirmação:** Tela de sucesso após a assinatura.

## 🎨 Design e Regras
O aplicativo foi estilizado seguindo regras específicas exigidas pela atividade:
- **Cor de Fundo:** Laranja (`#FF9F1C`) em todas as telas.
- **Campos de Texto (Inputs):** Bordas e arredondamentos configurados estritamente em **5px** de espessura/raio.

## 🚀 Como Executar Localmente
Para rodar este projeto em sua máquina:
1. Certifique-se de ter o Node.js instalado.
2. Instale as dependências: `npm install`
3. Execute o projeto: `npx expo start`
4. Leia o QR Code usando o aplicativo **Expo Go** em seu celular (iOS/Android).

## ☁️ Importando para o Expo Snack
Para visualizar e testar o código direto do navegador:
1. Acesse [snack.expo.dev](https://snack.expo.dev/)
